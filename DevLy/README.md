# DevLy
This project aims to build a secure, role-based online examination and learning platform for students, professors, and administrators. Students can register with OTP verification, access tutorials, execute code, take scheduled tests, and use an AI chatbot for doubt solving. Professors can create, edit, and manage programming tests with defined difficulty and duration. Administrators oversee student management, professor appointments, student promotions, and overall system monitoring. The platform centralizes learning, testing, communication, and administration into a single efficient digital system.
